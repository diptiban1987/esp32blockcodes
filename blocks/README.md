# TechyGuide Blocks Examples

This directory contains pre-made example block projects that can be opened instantly in the TechyGuide Blocks app (`https://block.techyguide.in`).

### Available Examples:
1. **`led_blink_pin13.techyguide`**:
   - **Board**: ESP32 / Arduino
   - **Pin**: Digital Pin 13
   - **Interval**: 1 Second (1000 ms)
   - **Description**: Turns LED on Pin 13 HIGH, waits 1 second, turns Pin 13 LOW, waits 1 second in a continuous loop.

### How to Open:
1. Open TechyGuide Blocks (`block.techyguide.in` or local app).
2. Go to top menu: **File** → **Load from your computer**.
3. Select `blocks/led_blink_pin13.techyguide`.
4. The workspace blocks will load instantly!
